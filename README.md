# 文军长征 — 浙江大学西迁文旅路线

一个以动画插画风格呈现的互动网站，展示抗日战争时期浙江大学西迁办学的壮丽历程。

## 项目简介

"文军长征"是浙江大学抗战时期西迁办学的壮举。1937年至1946年间，在校长竺可桢的带领下，浙大师生历经四次大规模迁移，辗转浙江、江西、湖南、广东、广西、贵州六省区，行程超过2600公里，在战火中保存了中华民族的教育火种，并创造了"东方剑桥"的传奇。

## 网站特色

- 动画插画风格 SVG 路线地图，带有绘制动画效果
- 点击各站点了解浙大师生在当地的经历
- 每站配有红色景区与革命遗址介绍
- 完整时间轴展示文军长征关键节点
- 响应式设计，适配桌面和移动设备

## 技术栈

- HTML5 / CSS3 / Vanilla JavaScript
- SVG 动画路线地图
- Google Fonts (Noto Serif SC / Ma Shan Zheng)
- GitHub Pages 托管
